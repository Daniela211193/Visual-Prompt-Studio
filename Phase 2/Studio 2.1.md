Visual Prompt Studio 2.1 

Prompt 1:

Create a painting that uses watercolors, to emphasize texture, balance, and space to illustrate a waterfall in the middle of a forest. It should also include the use of value and rhythm to show how sunny and the variety of trees there is. Use watercolors to show transparency and layering to demonstrate how clear but deep the water is at the bottom. The painting should have a glazing finish to really show the value of the painting.  

Prompt 2:

 Create a painting that uses serigraphy to emphasize texture, balance, and space to illustrate a waterfall in the middle of a forest. Vibrant coloring layering and a glazing finish should be used to define the value of the print, which should be sunny.
